# bslquery
Python package for querying the biosoundslab database.

## Installation
```
conda create -n biosoundslab python=3.12
conda activate biosoundslab
python -m pip install -r requirements.txt
```

## Running the examples
Start the notebooks
```
conda activate biosoundslab
pip install -e .
jupyter lab
```
Open the `00_Setup_DB_Connection` notebook and follow the instructions in the notebook to finish the setup.
